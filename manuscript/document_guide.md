## Inventory boundary

Top-level aggregate audit/*.json records are indexed except this builder's own verification receipt, which is hashed separately in the package manifest to avoid self-reference; nested temporary clinical-event partitions are excluded. Source/test/notebook files are indexed by metadata without copying private clinical records. Historical manuscript snapshots remain local provenance and are not mixed into the current paper. The table is a coverage inventory, not a claim that every historical document is accurate or every code path was rerun.
